# NLP Sentiment Analysis using BERT

## 📌 Objective

This project performs sentiment analysis using transformer-based models like BERT, Domain Adapted BERT, and BioBERT.

## 📊 Dataset

* IMDB Dataset
* Drugs Review Dataset

## ⚙️ Models Used

* BERT (baseline)
* Domain Adapted BERT (MLM + Fine-tuning)
* BioBERT

## 📈 Results

* Accuracy and F1-score comparison between models
* Visualization of results using matplotlib

## 🚀 How to Run

1. Install requirements:
   pip install -r requirements.txt
2. Run the code:
   python nlp_assignment_23051245.py

## 📦 Libraries Used

* PyTorch
* Transformers (HuggingFace)
* Pandas, NumPy, Matplotlib
